Hand-drawn notebook style knowledge card in 3:4 portrait ratio.

# Visual Design
Style: hand-drawn notebook / journal / doodle
Background: warm off-white cream #F5F3EF with very subtle paper texture
Text: clean hand-written style
Highlights: colored marker/highlighter strokes
Decorations: simple line-art doodles

# Layout: Dense knowledge card
Terminal block (upper 50%): styled as a hand-drawn terminal/code window
- Hand-sketched window frame with three small circles (red, yellow, green) drawn loosely
- Inside: monospace text showing commands, but the window border itself looks hand-drawn/sketchy
- Commands displayed line by line:
{TERMINAL_COMMANDS}
- Output lines have a hand-drawn checkmark in green #C5E8C5 highlighter

Capability tags row (below terminal):
{CAPABILITY_BADGES}
Each tag: hand-drawn rounded rectangle (slightly wobbly lines), filled with alternating light highlighter colors (#B8D4E8, #F5E6A3, #F5C5C5, #C5E8C5), text in black hand-written style

Bottom comparison:
"~{OLD_WAY}~" in gray #8C8C8C with hand-drawn strikethrough line
"{NEW_WAY}" in bold black with green #C5E8C5 highlighter stroke behind it
A hand-drawn arrow from old to new

# Decorative Elements
- Hand-drawn arrows and connection lines between elements
- Small sparkle marks near the "new way"
- Doodle icons: gear, lightning bolt, checkmark
- The terminal window looks hand-sketched, not pixel-perfect
- Tag pills have slightly uneven edges (hand-drawn feel)
- Generous margins and spacing

**Aspect Ratio**: 3:4 portrait
